User Authentication V2

Implementing OAuth2.0 and biometric login for enhanced security and smoother onboarding.

Status In Review
Target Release Q3 2024
Epic Core Security Upgrade

Executive Summary edit

The current authentication flow is seeing a 15% drop-off rate during password creation. V2 aims to reduce friction by introducing social logins (Google, Apple) and biometric support (FaceID/TouchID) on mobile. This will decrease time-to-first-value and improve our security posture by reducing reliance on weak passwords.

User Stories

US-101

As a new user, I want to sign up using my Google account so that I don't have to remember another password.

Priority: High Frontend
US-102

As a mobile user, I want to enable FaceID for subsequent logins to access the app faster.

Priority: Medium Mobile Apps

Acceptance Criteria

  • Google OAuth implementation follows official guidelines and requests only email and basic profile scope.

  • Fallback to standard email/password exists if biometric authentication fails 3 times.

  • Existing users can link their social accounts in the Settings > Security tab.
